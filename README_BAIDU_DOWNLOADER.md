一款专为解决百度网盘强制唤起/安装客户端而打造的高性能油猴脚本。直接在网页端提取真实高速下载链接（dlink），支持 **IDM（Internet Download Manager）一键调用/导出**、**Aria2/Motrix RPC 推送** 与 **网页内置直接下载**。

## 🌟 核心特性

- 🚀 **免装客户端**：直接在网页端提取文件的真实 `dlink` 直链，告别百度网盘官方桌面端。
- ⚡ **IDM 深度整合**：
  - **📁 导出 `.ef2` 任务导入清单**：内嵌专属客户端 User-Agent 与 Cookies，IDM 一键导入免配置。
  - **📄 生成 `.cmd` 一键启动脚本**：双击即可自动唤起 IDM 建立多线程下载任务。
  - **📋 复制 IDMan.exe 命令行**：支持在终端直接调用 IDM。
  - **⚙️ 一键复制 IDM 专用 UA**：方便 IDM 浏览器扩展直接无缝接管拦截。
- 📡 **Aria2 / Motrix RPC 推送**：支持配置本地或局域网 RPC 地址与 Token，秒级推送分块多线程下载。
- 🌐 **网页内置直接下载**：通过油猴底层流式拉取直接保存到本地，自带实时进度条。
- 🎨 **现代磨砂质感 UI**：支持暗黑风格模态弹窗、Toast 实时反馈与偏好设置持久化。

## 🛠️ 安装方法

1. 确保您的浏览器（Chrome、Edge、Firefox 等）已安装 **Tampermonkey（油猴）** 或 **ScriptCat（脚本猫）** 扩展。
2. 打开油猴扩展管理面板，点击 **“添加新脚本”**。
3. 将 [baidu_netdisk_direct_downloader.user.js](./baidu_netdisk_direct_downloader.user.js) 文件中的全部代码复制并粘贴到编辑器中保存。
4. 刷新百度网盘个人网盘（`pan.baidu.com/disk/main`）或任意分享链接页面即可生效。

## 🚀 IDM 配合使用说明

### 推荐方式 1：导出 `.ef2` 任务清单（最简单、免配置）
1. 在百度网盘页面勾选需要下载的文件。
2. 点击顶部的 **【⚡ 免客户端直链下载】** 按钮，弹出下载控制面板。
3. 在【🚀 IDM 专区】点击 **【📁 导出 IDM .ef2 任务】**，保存 `.ef2` 任务文件。
4. 打开 IDM 客户端，点击菜单栏：**`任务` -> `导入` -> `从 ef2 文件导入`**，选择刚下载的文件，IDM 即可带上官方特征满速下载！

---

### 推荐方式 2：生成 `.cmd` 一键调用批处理
1. 在控制面板中点击 **【📄 生成 .cmd 一键调用】**。
2. 浏览器会自动下载一个 `.cmd` 脚本文件。
3. **双击运行该 `.cmd` 文件**，系统会自动调用您电脑上的 `IDMan.exe` 并添加下载任务。

> [!TIP]
> 如果您的 IDM 安装在非默认目录，可在脚本面板的【⚙️ 偏好设置】中修改 `IDMan.exe` 的绝对路径并保存。

---

### 推荐方式 3：IDM 浏览器扩展直接拦截
1. 在脚本面板点击 **【⚙️ 复制 IDM 专用 UA】**。
2. 打开 IDM 软件菜单：**`选项` -> `下载` -> `手动添加任务` -> 在 `用户代理 (User-Agent)` 框中粘贴** 该 UA（`netdisk;11.24.3;PC;PC-Windows;...`）。
3. 之后在控制面板点击下载或直链，IDM 浏览器扩展将自动捕获并高速下载。

## 📡 Aria2 / Motrix RPC 推送配置

1. 打开脚本控制面板，切换到 **【⚙️ 偏好设置】**。
2. 配置您的 RPC 服务信息：
   - **RPC 地址**：默认为 `http://localhost:6800/jsonrpc`（Motrix 默认端口为 `16800`）。
   - **RPC Token**：若有密码则填写，无密码留空。
3. 点击 **【💾 保存所有配置】**。
4. 勾选文件后，在【📡 Aria2 / Motrix】选项卡点击 **【立即推送到 Aria2 / Motrix】** 即可。

## ❓ 常见问题 (FAQ)

**Q: 提示“暂不支持直接下载文件夹”？**
> **A:** 百度网盘官方 API 不支持对整个文件夹直接生成单个 `dlink`。请双击进入文件夹，勾选其中的一个或多个具体文件后再点击下载。

**Q: 提取直链时提示解析失败或错误码？**
> **A:** 百度网盘对于部分频繁下载或未登录用户可能会触发风控。请确保当前百度网盘处于正常登录状态。如果是分享链接，请确保该分享链接未被取消或失效。

**Q: 直链下载后提示 403 Forbidden？**
> **A:** 百度网盘直链必须携带专用的 User-Agent（`netdisk;...`）和当前网页的 Cookies。直接使用普通浏览器下载器可能会被限速或拦截，强烈建议使用脚本提供的 **【导出 IDM .ef2】** 或 **【Aria2 RPC 推送】**。
